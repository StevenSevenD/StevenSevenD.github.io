# StevenSevenD · 游戏研发工具作品集

公开入口：https://stevensevend.github.io/

以 GitHub Pages 托管的静态作品集。工具源码继续在各自仓库维护；此仓库仅包含展示页、介绍和已允许展示的截图。私有仓库不会因链接或展示而变为公开。

## 本地预览

在仓库目录运行 `python -m http.server 4173`，访问 `http://localhost:4173`。页面通过 fetch 加载项目数据，不能用 file:// 直接预览。

## 添加工具

在 projects.json 中增加一条记录，使用唯一 id，并填写名称、用途、功能、技术栈、版本、边界、仓库和说明链接。把展示图片放入 assets/，明确标注实际截图或功能示意。现有分类是 desktop 和 engine；其他分类需同步增加首页筛选按钮。总数和分类数量自动计算。无公开源码时将 repo 设为 null。

维护流程：修改内容 → 执行 `node --test tests/site.test.cjs` → 检查本地页面 → git commit → git push。GitHub Pages 从 main 分支根目录自动更新，分享链接不变。

## 内容依据与验证

三个工具介绍依据各自 README 和使用说明，未添加未经确认的履历、业务指标或用户评价。战斗模拟器使用真实 0.6.1 自检截图；另两个工具使用明确标注的功能示意图。网页提供分类筛选、项目详情、图像展示和公开仓库/说明入口。浏览器验证和发布结果见发布交付消息。
